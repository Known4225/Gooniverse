# Gooniverse

Character map from "A Visit From the Goon Squad" and "The Candy House" by Jennifer Egan showing character relationships.

![Image](images/Gooniverse2.JPG)

# How to use
- Click on a character to see all the connections this character has
- Hover over a group in the right sidebar to see what characters are members of that group
- Characters can be dragged around with the mouse
- You can select multiple characters by holding shift and clicking
